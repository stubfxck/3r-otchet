# Страницы для компаний

Статичные страницы, которые открываются прямо в браузере. Публикуются через GitHub Pages: `https://stubfxck.github.io/company-pages/`.

| Страница | Папка |
|---|---|
| **Три-R** - отчёт по заявкам из выгрузки AMO | `3r/` |
| Панель показателей: двери, плитка, полы (пример оформления, данные условные) | `dveri-plitka-poly/` |

## Правила репозитория

- У каждой страницы своя папка с `index.html`. Оглавление - `index.html` в корне.
- **Данные сюда не кладём.** Выгрузки и любые данные компаний в репозиторий не попадают: `.gitignore` блокирует .xlsx, .csv, .json и т.п.
- **Три-R не отправляет данные никуда.** Файл читается в браузере, выгрузки хранятся только в памяти самого браузера пользователя.
- Все страницы открываются с одного адреса `stubfxck.github.io`, поэтому делят между собой память браузера. Публиковать здесь стоит только свой код без чужих скриптов.
- Страницы закрыты от поисковиков (`noindex`), но по ссылке открываются у всех: не выкладывайте то, что должно быть секретным.
