# 3R - отчёт по заявкам

Страница-инструмент: загружаете выгрузку из AMO (.xlsx) и получаете отчёты.

**Данные не отправляются никуда.** Файл читается прямо в браузере на вашем устройстве и нигде не сохраняется, кроме памяти
этого браузера (localStorage). В репозитории нет ни выгрузок, ни данных, только сама страница `index.html`.

Публикуется через GitHub Pages. Выгрузки коммитить в репозиторий нельзя (см. `.gitignore`).
